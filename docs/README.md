# 课题资料与实验协议

保存课程题目、选题记录和后续实验协议。

- `模式识别题目.pdf`：课程原始题目资料。

1. 01_project_structure.md

项目结构、模块作用、训练与测试执行流程，以及主要函数调用关系。

2. 02_objective_checklist.md

完整的研究目标对照表。
这是最重要的文件，必须逐项列出研究目标、实现位置、测试状态与证据。

3. 03_code_issues.md

代码问题清单。
按严重程度分类：
Critical：数据泄漏、算法错误、结果错误等。
High：影响实验有效性或可复现性。
Medium：实现不完善、配置不合理等。
Low：注释缺失、命名不规范等。

4. 04_results_verification.md

现有实验结果真实性和可复现性审查。
需要区分：
已成功运行且有充分证据。
有结果但缺少完整证据。
代码存在但没有运行记录。
运行失败。
未开展实验。

5. 05_missing_experiments.md

缺失实验清单、补充实验方案、优先级及预计需要的计算资源。

6. 06_recommended_next_steps.md

根据当前项目真实进度，制定可以逐步完成的工作计划。
优先修复影响实验正确性的问题，再补充必要的对比实验，最后考虑模型改进。

# 报告与展示

`docs/reference/A03_模式识别开题报告.pdf` 是当前研究依据。正式报告应基于至少 3 个随机种子、固定测试任务与经审核的 NABirds 物种清单，分别报告 CUB 未见类和跨数据集 1-shot/5-shot 结果、置信区间与错误分析。单次贯通检查不能作为实验结论。

CUB 验证结果索引见 `cub_progress_2026-10-23.md` 与 `cub_followup_2026-10-23.md`；后者包含上下文 Matching Networks、监督最近类中心、长预算及人工错误抽样。两份文件中的后续模型实验均不得与第一轮 CUB 测试结果混写为新的独立测试结论。

# 开题报告任务进展：CUB 范围（2026-10-23）

本报告对照 [开题报告](../docs/reference/A03_模式识别开题报告.pdf) 的 CUB 实验任务整理现有证据。NABirds 测试不在本轮范围。**除第一轮固定方案外，下面新增数字均来自 CUB 验证类；CUB 测试类此前已经被查看，不能把后续调参后的同一测试集复评当成全新盲测。**

## 统一数据与限制

- CUB 官方元数据对应 200 类、11,788 张索引图像；工程划分为训练 100 类 / 5,890 图、验证 50 类 / 2,947 图、测试 50 类 / 2,951 图，类别与图像清单互斥。`scripts/validate_cub.py --check-images` 本轮重新通过。
- 训练对照默认 5-way、每类 1 个 query、224×224、种子 42/43/44、每种子 3 epoch × 30 个训练 episode、固定 30 个验证 episode。每种子在自己的固定验证任务上选最佳 epoch。除标注的监督阶段外，优化器为 Adam、学习率 1e-4。
- ImageNet 监督 ResNet-18 使用 `ResNet18_Weights.IMAGENET1K_V1`；自监督对照为 [Diaz/Henderson 的 ImageNet-1K SimCLR ResNet-18](https://huggingface.co/DM-Diaz/SimCLR-ResNet18-ImageNet1K)。原 SimCLR 项目公布的主要权重为 ResNet-50，不能直接充当 ResNet-18 对照。所用具体权重的哈希、编码器提取方式见 [来源记录](records/simclr_weight_provenance.json)。
- 以下“准确率”是验证集描述性均值，默认每种子只有 150 个 query 决策，且各 epoch 共用验证任务；不以这些数值作无偏测试置信区间或跨数据集推断。不同预训练权重的训练数据、时长和批量也不同，差异不能仅归因于“监督/自监督”标签。

## 训练后的匹配方式

下表方法均从相同的监督预训练 ResNet-18 开始，冻结主干、训练线性适配层。对应种子复用验证任务。5-shot 的前四行是**专门按 5-shot 训练**；Meta-Baseline 使用 1-shot 训练检查点复评 5-shot，应单独解释。

| 方法 | 1-shot 验证均值 | 5-shot 验证均值 | 运行位置 |
| --- | ---: | ---: | --- |
| ProtoNet，全局余弦 | 78.44% | 92.44% | `outputs/cub_study_v1/`、`outputs/cub_5shot_selection_v1/` |
| DN4 式局部匹配 | 68.00% | 87.33% | `outputs/cub_method_ablation_v1/` |
| 全局 + 局部，权重 0.5 | 76.67% | 91.11% | `outputs/cub_study_v1/`、`outputs/cub_5shot_selection_v1/` |
| 简化 MatchingNet 注意力 | 与 1-shot 余弦原型决策等价 | 89.78% | `outputs/cub_method_ablation_v1/` |
| Meta-Baseline 风格：2 个监督 epoch + 3 个 episodic epoch | 78.44% | 91.33%（复评 1-shot 检查点） | `outputs/cub_meta_baseline_v1/` |

1-shot 简化 MatchingNet 每类只有一个 support，softmax 注意力的最大类别与余弦原型最大类别相同；这是实现的数学退化，不代表完整上下文 Matching Networks 已完成多种子训练。Meta-Baseline 的额外监督阶段使训练预算不同，不能把它与短训 ProtoNet 的差异单独归因于算法。训练后的 DN4 和固定 0.5 融合在当前协议下都未超过全局 ProtoNet。

## 固定编码器特征下的匹配和距离

为了只改变匹配规则，`scripts/compare_cub_matching.py` 对 CUB **验证图像**各编码一次，使用相同的冻结监督预训练特征、相同的 5-way episode 和种子 42/43/44；每种子每 shot 为 100 个 episode。这里不训练任何参数。完整逐种子结果和计划哈希在 [固定特征记录](records/cub_fixed_feature_v1.json)。

| 规则 | 1-shot 均值 | 5-shot 均值 |
| --- | ---: | ---: |
| 全局余弦原型 | 72.27% | 91.67% |
| 全局平方欧氏原型 | 65.73% | 91.27% |
| 支持集协方差收缩马氏原型（收缩 0.5） | 71.13% | 91.73% |
| 支持集统计量标准化 + 余弦原型 | 69.27% | 92.33% |
| 简化 MatchingNet 注意力 | 72.27% | 88.27% |
| DN4 式局部匹配 | 65.80% | 83.93% |
| 全局/局部各占 0.5 | 71.33% | 90.20% |

三个种子在这里是**不同的 episode 计划**，不是三个独立训练的模型。5-shot 标准化与全局余弦只差 0.66 个百分点，不能凭此宣布改进；固定特征实验与训练后实验的预算不同，数字不可合并成一个模型排名。

## 初始化与适配范围

首先固定主干、仅训练线性适配层，并保持同一训练/验证 episode 协议，比较三种具体初始化：

| 初始化 | 1-shot 验证均值 | 5-shot 验证均值 |
| --- | ---: | ---: |
| 随机初始化、主干冻结（负对照） | 25.33% | 33.78% |
| 指定 SimCLR 自监督权重、主干冻结 | 31.78% | 46.44% |
| 指定 ImageNet 监督权重、主干冻结 | 78.44% | 92.44% |

原始运行分别在 `outputs/cub_random_frozen_v1/`、`outputs/cub_simclr_v1/`、`outputs/cub_study_v1/` 与 `outputs/cub_5shot_selection_v1/`。随机**冻结**主干是负对照，不能称为从零训练全网络。SimCLR 权重来自另一研究的 100 epoch、batch 32 训练，数据来源为其模型卡注明的 ImageNet-1K 派生集；其低成绩只适用于这份具体权重和当前预处理、短训协议。两种外部预训练均有与 CUB 来源图像可能重合的未审计风险。

另以 **1-shot 训练检查点**比较适配范围；5-shot 列是这些检查点在固定 5-shot 验证任务上的复评，不等同于专门 5-shot 训练：

| 初始化 / 可训练范围 | 1-shot 最佳 epoch 验证均值 | 5-shot 复评验证均值 |
| --- | ---: | ---: |
| ImageNet 监督 / 仅线性适配层 | 78.44% | 91.33% |
| ImageNet 监督 / 最后残差层 + 适配层 | 78.00% | 86.44% |
| ImageNet 监督 / 全网络 | 74.22% | 90.89% |
| 随机初始化 / 全网络 | 28.89% | 30.67% |

运行记录在 `outputs/cub_scope_v1/`；基线适配层在 `outputs/cub_study_v1/`。短训练中更大的可训练范围没有稳定改善验证准确率；随机全网络训练仍仅接受 90 个训练 episode，不能据此判断充分训练的从零模型上限。全量/最后一层优化也改变了参数量和收敛速度；要研究训练充分后的差异，应另设预算并按验证集检查收敛。

## 第一轮 CUB 测试与错误分析

唯一已有的多种子 CUB **测试**比较是预先固定权重 0.5 的 ProtoNet 对融合模型：[第一轮报告](cub_study_v1.md)。1-shot 配对均值差为 −1.23 个百分点（95% CI −3.03 至 0.56），5-shot 差为 +0.57 个百分点（95% CI −0.23 至 1.37）；均不能据此宣称融合稳定提升。5-shot 测试复用了按 1-shot 验证任务选出的检查点。

`scripts/analyze_cub_errors.py` 没有再次运行模型，只读取第一轮已保存的 12 份 query 预测，并结合 CUB 官方边界框。按**全部 2,951 张测试图像**的边界框矩形占图像面积分四组，阈值为 20.95%、31.70%、45.33%。三种子 pooled query 决策中的准确率如下：

| 方法与任务 | 最小面积组 | 第二组 | 第三组 | 最大面积组 |
| --- | ---: | ---: | ---: | ---: |
| ProtoNet 1-shot | 77.49% | 81.77% | 81.74% | 81.57% |
| 融合 1-shot | 76.13% | 80.05% | 80.54% | 80.92% |
| ProtoNet 5-shot | 90.18% | 89.47% | 92.11% | 92.86% |
| 融合 5-shot | 90.46% | 90.42% | 92.62% | 93.38% |

这只是描述性关联：同一图像可在多个 episode 重复出现，边界框面积不是鸟体像素面积，也不能推断姿态、遮挡或背景造成错误。[错误审计 JSON](records/cub_error_audit_v1.json) 保存来源哈希、分组计数和独立图像数；[人工复核 CSV](records/cub_error_review_v1.csv) 列出 1,708 条错误决策，并将姿态、光照、背景、遮挡、标签疑点栏留空等待人工看图，不伪造错误归因。
